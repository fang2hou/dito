# Dito 音声認識の接続設定仕様 v1

Dito が受け付ける音声認識用 JSON 設定の形式と制約。末尾のテンプレートは参考例であり、接続先の URL、認証方式、リクエストとレスポンスの形式はサービスの API 仕様によって異なります。モデル ID は利用者が指定する必須の文字列で、固定の候補や既定値はありません。

## 構成

- `version`：`1`。
- `connection`：`base_url` と `model`。`base_url` は HTTP または HTTPS のベース URL で、中継サーバーのパスやポートを含められます。最終リクエストのパス、クエリ、フラグメントは含めません。
- `language_map`：Dito の言語コードから、接続先が要求する値への変換表。
- `request`：`method`、`path`、`headers`、`encoding`、必要に応じて `query`、`body` または `fields`。
- `response`：認識結果を取得する `text_pointer` と、任意の `language_pointer`。

## 言語コード

言語は「一般」の優先言語設定から渡されます。画面の表示言語とは別の設定です。接続設定内には独立した言語選択はありません。

### 現在 Dito が渡す言語コード

| 全体の優先言語設定 | Dito 内部の値 | `language_map` のキー |
| --- | --- | --- |
| 日本語 | `ja` | `ja` |
| 英語 | `en` | `en` |
| 中国語 | `zh` | `zh` |
| 自動 | 未指定（`null`） | 予約キー `auto` |

現在の優先言語設定が渡す値は、この3つの言語コードと「自動」のみです。「自動」では文字列 `auto` を送るのではなく、言語を未指定として扱い、マッピング時に予約キー `auto` を参照します。`other` は未知の言語用の予約キーで、言語の選択肢ではありません。

`ja-JP`、`en-US`、`zh-CN`、`JP`、`EN`、`Japanese` などは、現在の設定から渡される内部コードではありません。接続先がこれらを要求する場合は、例えば `"ja": "JP"` のように右側の値へ変換します。地域付きの入力キーにも対応する形式ですが、現在の設定が地域付きコードを生成するわけではありません。中国語の内部コードは `zh` で、`cn` ではありません。

キーには `ja`、`en`、`zh`、`ja-JP` などの言語タグを使います。`JP` は国コードなので、日本語のキーは `ja` または `ja-JP` です。値は接続先の仕様に合わせ、`ja`、`JA`、`JP`、`Japanese` などをそのまま送ります。値の大文字・小文字は保持します。

照合順序は「完全な言語タグ → 主言語 → `other`」です。キーは大文字・小文字を区別せず照合し、重複するキーは使えません。`other` は必須の空でない文字列で、最後の項目です。未知の言語にはこの値を使います。`other` 以外の値には `null` も指定できます。

`auto` は未知の言語とは別です。`auto` が未定義、または `"auto": null` の場合、言語フィールドを送信しません。文字列を明示した場合はその値を使います。接続先に言語パラメーターがない場合、言語フィールドは不要です。

## リクエスト

`method` は `POST` または `PUT`。`path` は `/` で始まる相対パスで、完全な URL、クエリ、フラグメントは使えません。ベース URL の末尾に追加し、中継サーバーのパスを保持します。例えば `https://relay.example.com/vendor/v1` と `/chat/completions` は `https://relay.example.com/vendor/v1/chat/completions` になります。

`encoding` が `json` なら `body`、`multipart` なら `fields` に対応し、両方の混在は無効です。`body` は入れ子のオブジェクトや配列に対応します。`query` と `fields` の値には文字列、数値、真偽値、`null`、`headers` の値には文字列を使います。Content-Type と multipart の boundary は Dito が設定します。クエリの URL エンコードと JSON の文字列エスケープも Dito が行います。

この形式は同期 HTTP 用です。WebSocket、タスクのポーリング、複数段階のアップロードは表現できません。

## 変数

- `{{model}}`：`connection.model`。
- `{{language}}`：変換後の言語コード。
- `{{api_key}}`：現在のプラットフォームの API キー。
- `{{audio.base64}}`：WAV 音声の Base64。接頭辞なし。
- `{{audio.data_uri}}`：`data:audio/wav;base64,` を含む音声文字列。
- `{{audio.file}}`：multipart のバイナリ WAV。`fields` の値全体としてのみ使用できます。

実際の API キーや録音データは設定に含めません。認証には `{{api_key}}` を使います。変数は固定の置換値であり、式やスクリプトは実行できません。未定義の変数はエラーです。

`"{{language}}"` が値全体で、変換結果が `null` なら、そのオブジェクトのフィールドを省略します。文字列の一部や配列の要素としては使えません。明示的に書いた JSON の `null` は保持されます。

## 認識結果

`text_pointer` と任意の `language_pointer` は JSON Pointer です。例：`/text`、`/output/text`、`/choices/0/message/content`。配列の添字は数値、`~` と `/` のエスケープは `~0` と `~1` です。認識結果は文字列である必要があり、前後の空白を除去します。言語の取得結果で Dito の全体設定は変更しません。
